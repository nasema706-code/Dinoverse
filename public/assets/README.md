# Dinoverse assets

Drop every image and video you want to use in this folder. This is the one place for new pictures and clips.

- Images: `.jpg` `.jpeg` `.png` `.webp` `.gif` `.svg` `.avif`
- Videos: `.mp4` `.webm` `.mov`

A file named `plaza-night.jpg` is available on the site as `/assets/plaza-night.jpg`.

Open **Assets** in the site menu to see everything here and copy each path.

Subfolders work too: `posters/launch.jpg` is `/assets/posters/launch.jpg`.
